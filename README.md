This is an in-development project for ComputerCraft, the Minecraft mod that adds Lua based computing.

CCCookies (ComputerCraft Cookies) is a Cookie Clicker Game for ComputerCraft. Using cryptography, players connect to a centralised server that stores their data, and can play the game.

Planned features include:
- The Game (which isn't done yet.)
- Leaderboard functionality
- Upgrades/Buildings/etc
